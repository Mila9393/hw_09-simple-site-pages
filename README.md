# Simple Site — послідовні версії домашніх робіт

Цей репозиторій використовується для публікації послідовних версій одного навчального проєкту **Simple Site** на GitHub Pages.

Кожне наступне домашнє завдання продовжує роботу над сайтом, створеним у ДЗ 9.

## Важливо

Файли, розташовані безпосередньо в корені репозиторію, належать до **ДЗ 9**.  
Адаптивна версія для **ДЗ 10** розміщена в окремій папці `hw_10/`.
Версія зі SCSS-рефакторингом для **ДЗ 11** розміщена в папці `hw_11/`.
Доопрацьована версія після уроку 12 розміщена в папці `hw_12/`.

Файли ДЗ 9 не переміщувалися, щоб зберегти початкову адресу вже опублікованої сторінки.

## Структура репозиторію

```text
hw_09-simple-site-pages/
├── index.html          ← ДЗ 9: початкова десктопна версія Simple Site
├── css/                ← стилі ДЗ 9
├── images/             ← зображення ДЗ 9
├── hw_10/
│   ├── index.html      ← ДЗ 10: адаптивна версія Simple Site
│   ├── css/            ← стилі та медіазапити ДЗ 10
│   └── images/         ← зображення ДЗ 10
├── hw_11/
│   ├── index.html      ← ДЗ 11: версія після SCSS-рефакторингу
│   ├── README.md       ← пам'ятка про чисту публікацію
│   ├── css/            ← фінальний скомпільований CSS
│   └── images/         ← SVG-іконки, потрібні сторінці
├── hw_12/
│   ├── index.html      ← ДЗ 12: доопрацьована версія ДЗ 11
│   ├── README.md       ← опис рекомендацій та доопрацювання
│   ├── css/            ← фінальний скомпільований CSS
│   └── images/         ← SVG-іконки, потрібні сторінці
└── README.md           ← пояснення структури репозиторію
```

## Опубліковані версії

| Домашнє завдання | Версія проєкту | Розташування | Робоча сторінка |
|---|---|---|---|
| ДЗ 9 | Початкова десктопна версія Simple Site | корінь репозиторію | [Відкрити ДЗ 9](https://mila9393.github.io/hw_09-simple-site-pages/) |
| ДЗ 10 | Адаптивна версія з медіазапитами | `hw_10/` | [Відкрити ДЗ 10](https://mila9393.github.io/hw_09-simple-site-pages/hw_10/) |
| ДЗ 11 | Рефакторинг із використанням SCSS | `hw_11/` | [Відкрити ДЗ 11](https://mila9393.github.io/hw_09-simple-site-pages/hw_11/) |
| ДЗ 12 | ДЗ 11 із доопрацьованою структурою SCSS | `hw_12/` | [Відкрити ДЗ 12](https://mila9393.github.io/hw_09-simple-site-pages/hw_12/) |

## Принцип зберігання версій

- ДЗ 9 залишається в корені репозиторію без змін.
- Кожний наступний етап розміщується в окремій папці.
- Назва папки відповідає номеру домашнього завдання: `hw_10/`, `hw_11/`, `hw_12/` тощо.
- Усі версії одного навчального сайту зберігаються в одному репозиторії GitHub Pages.
- Кожна версія має власну постійну адресу та не перезаписує попередню.
